# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x (current `master`) | ✅ |

## Reporting a vulnerability

This is a fully client-side static app (no backend, no user accounts), so the attack surface is small — but please still report responsibly:

1. **Do not** open a public issue for security vulnerabilities.
2. Email **theanilpaneru@gmail.com** with a description, steps to reproduce, and impact.
3. Allow reasonable time for a fix before any public disclosure.

We will acknowledge your report, fix verified issues promptly, and credit you (if desired) in the release notes.
